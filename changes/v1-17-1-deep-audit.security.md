Hardened native statistical acceleration (`native/src/_accel.c`), multi-objective Pareto frontier extraction (`gunz_utils.stats`), optimistic file snapshots (`gunz_utils.io`), dynamic plugin loading (`gunz_utils.plugins`), and directory traversal/fingerprinting (`gunz_utils.fs`):

- Fixed 9 `PyObject` reference leaks per `py_fast_summary` call in `native/src/_accel.c`, added allocation size-overflow and OOM checks, aligned `coefficient_of_variation` near-zero mean threshold (`1e-15`) with the pure-Python fallback, and delegated custom `Real` inputs (such as `Fraction`) and non-finite Welford intermediates to the pure-Python fallback.
- Restored exact oracle equivalence between `pareto_frontier` (1D/2D $O(N \log N)$ sweep) and `pareto_dominates` at sub-$10^{-15}$ coordinate scales, enforced eager `objectives` validation before empty-input short-circuiting, made `RunningStats.extend` failure-atomic across generator inputs, and guarded `RunningStats` against non-finite intermediate overflow.
- Eliminated the split read/stat TOCTOU window in `read_file_snapshot(max_bytes=...)` by reading and `fstat`-verifying a single `O_NOFOLLOW` descriptor, and verified on-disk `lstat()` identity before the no-op short-circuit in `FileSnapshot.write_if_unchanged`.
- Hardened `GunzFileFinder.find_spec` and `load_module_from_path` to reject symlinks and non-regular files via `lstat()` prior to path resolution, validated `walk_files` arguments eagerly on invocation, and hardened `tree_fingerprint` with `SUPPORTED_ALGOS` validation, length-prefixed path framing, and signed 64-bit `st_mtime_ns` encoding.
