## 1. Goal

Establish the `PerformanceRun v1` portable JSON specification, execution harness, and self-describing artifact packager to standardize benchmark, profiling, and model evaluation runs across Gunz repositories (`gunz-bench`, `hyperhedron-mlx`, `gunz-ml`).

## 2. Scope

### In Scope

- **Data Models & Schema (`gunz_utils.benchmark.model`)**:
  - `PerformanceRun`: Top-level container with schema version `1.0.0`, run UUID, timestamp, git metadata, and environment snapshot.
  - `SystemEnvironment`: CPU model, core/thread topology, total/available memory, OS version, cgroup/container memory limits, and explicit allowlist of environment variables.
  - `MeasurementSample`: Raw latency samples, memory metrics, iterations, warmup counts, and per-trial status (`ok`, `failed`, `timeout`).
- **Worker Execution Protocol**:
  - Isolated subprocess execution worker to run benchmarks in fresh interpreter instances, eliminating heap fragmentation and GC contamination between trials.
  - Structured communication over stdout via canonical JSONL stream.
- **Artifact Bundle Packager**:
  - Packager that writes self-describing directory bundles: `run.json` (metadata & summary), `samples.jsonl` (raw measurement stream), and `environment.json` (hardware/OS capture).
- **Unit & Contract Tests**:
  - Serialization round-trip validation using `gunz_utils.testkit`.
  - Schema immutability and schema-version backward compatibility.

### Out of Scope

- Statistical regression alerting (deferred to reporting engine).
- External visualization dashboards (HTML/Plotly).
