## 3. API design

```python
from gunz_utils import Timer, timer

# As a context manager
with Timer() as t:
    do_something_slow()
print(f"took {t.elapsed}s")  # "took 1.234s"

# With a label (uses t.label attribute; doesn't auto-log)
with Timer("import torch") as t:
    import torch
print(f"{t.label}: {t.elapsed}s")  # "import torch: 0.523s"

# Manual start/stop (useful when you can't use `with`)
t = Timer()
t.start()
do_work()
t.stop()
print(t.elapsed)

# Convenience: timer() returns a started Timer
t = timer()
do_work()
print(t.elapsed)

# Already-started Timer (no manual start)
t = Timer("operation X")  # started immediately in __init__
```

### Implementation

```python
# timing.py

import time
import contextlib

__all__ = ["Timer", "timer"]

class Timer:
    """Context manager for measuring elapsed wall-clock time.

    Usage:
        with Timer() as t:
            ...
        print(t.elapsed)

    Or manual:
        t = Timer()
        t.start()
        ...
        t.stop()
        print(t.elapsed)
    """

    def __init__(self, label: str | None = None, *, auto_start: bool = True):
        self.label = label
        self._start_time: float | None = None
        self._end_time: float | None = None
        if auto_start:
            self.start()

    def start(self) -> None:
        """Mark the start of the timed interval. Idempotent on re-start."""
        self._start_time = time.perf_counter()
        self._end_time = None

    def stop(self) -> None:
        """Mark the end of the timed interval. Idempotent on re-stop."""
        if self._end_time is None:
            self._end_time = time.perf_counter()

    @property
    def elapsed(self) -> float:
        """Seconds elapsed. If still running, returns time since start.
        If not started, returns 0.0.
        """
        if self._start_time is None:
            return 0.0
        end = self._end_time if self._end_time is not None else time.perf_counter()
        return end - self._start_time

    def __enter__(self):
        if self._start_time is None:
            self.start()
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.stop()
        return False  # don't suppress exceptions

@contextlib.contextmanager
def timer(label: str | None = None):
    """Convenience: yield a started Timer. Stops automatically on exit."""
    t = Timer(label, auto_start=True)
    try:
        yield t
    finally:
        t.stop()
```

## 4. Test plan

`tests/test_core/test_timing.py` — ~10 tests:

1. **Context manager measures elapsed** — `with Timer() as t: time.sleep(0.01); assert t.elapsed >= 0.01`
2. **`label` attribute preserved** — `with Timer("foo") as t: ...; assert t.label == "foo"`
3. **Manual start/stop** — `t = Timer(auto_start=False); t.start(); ...; t.stop(); assert t.elapsed > 0`
4. **`elapsed` before start is 0** — `t = Timer(auto_start=False); assert t.elapsed == 0.0`
5. **`elapsed` while running** — `t = Timer(); time.sleep(0.01); assert 0.01 <= t.elapsed < 0.5`
6. **`elapsed` after stop is fixed** — `t = Timer(); t.stop(); e1 = t.elapsed; time.sleep(0.1); e2 = t.elapsed; assert e1 == e2`
7. **`__exit__` auto-stops** — `with Timer() as t: pass; assert t._end_time is not None`
8. **`__exit__` doesn't suppress exceptions** — `with pytest.raises(ValueError): with Timer() as t: raise ValueError; assert t._end_time is not None`
9. **`timer()` context manager** — `with timer("x") as t: pass; assert t.label == "x"`
10. **`restart` semantics** — `t = Timer(); t.start(); t.stop(); t.start(); assert t._end_time is None`
