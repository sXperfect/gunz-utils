## 1. Goal

Design and formalize the three-tiered native C/C++ acceleration architecture and low-overhead telemetry specification for `gunz-utils` to resolve the telemetry observer effect and computational limits of pure-Python statistical loops, while preserving zero-dependency pure-Python installation invariants.

## 2. Scope

### In Scope

- **Structural Definition (`docs/design/definitions/native_acceleration.yaml`)**:
  - Defines the component schema, modules (`gunz_utils._accel`, `gunz_utils.telemetry`, `gunz_utils.stats`), methods, argument types, and return contracts.
- **System Requirements Specification (`docs/design/specs/native_acceleration.md`)**:
  - Formalizes observable equivalence, pure-Python fallback, missing-metric representation, Darwin Mach `libproc` bindings, Linux procfs fast paths, and hardware cycle counters.
- **Architectural Guide (`docs/design/native-acceleration-architecture.md`)**:
  - Detailed technical rationale for the three-tiered hierarchy (Tier 0 pure Python, Tier 1 standard-library `ctypes` OS bindings, Tier 2 optional compiled C extension).
  - Observer effect analysis, Darwin `libproc` C integration, SIMD bootstrap resampling, and inline assembly cycle counting.
- **Repository Task & Release Governance**:
  - Update `docs/TASKS.md` and `docs/TASKS_ARCHIVE.md`.
  - Add documentation changelog fragment in `changes/`.

### Out of Scope

- Introducing mandatory compiled binaries to the core package distribution.
- External dependencies on third-party profilers (e.g. `psutil`).
