## 1. Goal

Optimize GitHub Actions CI pipeline for credit-conscious execution on free-tier runners (timeout limits, ephemeral artifact retention, docs-only fast-path filtering), introduce a zero-dependency standalone test runner (`scripts/run_tests.py`), and update comprehensive CI design documentation.

  - Consolidate pip install arguments (`--no-input --disable-pip-version-check`).
  - Add `--skip-compat` flag in `scripts/audit_ci.py` and invoke it in CI when a pull request touches only docs/markdown files.

- **Standalone Zero-Dependency Test Runner**:
  - Provide `scripts/run_tests.py` using standard-library `unittest` to allow developers on fresh/ambient environments without global pytest to verify core tests immediately.
- **Design & Reference Documentation**:
  - Update `docs/design/audit/ci-strategy.md` with credit-conscious architecture section.

- Changing core package runtime dependencies.
