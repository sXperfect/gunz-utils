# Task: native-binary-acceleration

**Date:** 2026-10-01
**Role:** Systems Architect / Core Maintainer
**Component:** `native/`, `src/gunz_utils/binary.py`, `scripts/build_native.py`, `tests/test_core/test_binary_accel.py`
**Status:** Completed

## 1. Goal

Implement the first phase of native C acceleration for `gunz-utils` by providing a high-performance C extension for 64-bit unsigned varint encoding/decoding and binary buffer parsing (`gunz_utils.binary`), while strictly preserving the Tier 0 pure-Python fallback contract and aligning architecture docs with `gunz-bench` separation.

## 2. Scope

### In Scope

- **Architectural & Design Realignment**:
  - Update `docs/design/native-acceleration-architecture.md`, `docs/design/definitions/native_acceleration.yaml`, and `docs/design/specs/native_acceleration.md` to formally reflect that all benchmarking/telemetry is owned by `gunz-bench`, while `gunz-utils._accel` focuses on core utilities (starting with varints in `gunz_utils.binary`).
- **Native C Implementation (`native/`)**:
  - `native/include/gunz_utils_native.h` declaring `gunz_native_encode_uvarint` and `gunz_native_decode_uvarint`.
  - `native/src/_accel.c` implementing pure C11 algorithms and CPython C API bindings.
  - Correct error signaling and exact parity with Python exceptions (`ValueError` for >64-bit, non-canonical, or negative; `EOFError` for truncated buffers).
- **Zero-Dependency Native Compiler Script**:
  - `scripts/build_native.py` building `src/gunz_utils/_accel<ext_suffix>` across macOS (clang), Linux (gcc/clang), and Windows (cl.exe).
- **Pure-Python Fallback & Transparent Dispatch**:
  - Wire `gunz_utils.binary` to use `gunz_utils.buffers.dispatch`.
  - Seamless fallback to reference pure Python if `_accel` is not compiled or fails to load.
- **Contract & Regression Testing**:
  - `tests/test_core/test_binary_accel.py` testing roundtrip parity, boundary values (0, 1, 127, 128, 2^64-1), canonicality rejection, buffer overflow/truncation, and non-canonical zero encoding.
- **Governance**:
  - Verify `ruff`, `mypy`, `pytest`.
  - Add changelog fragment.

### Out of Scope

- Benchmarking or telemetry timers in `gunz-utils` (permanently delegated to `gunz-bench`).
