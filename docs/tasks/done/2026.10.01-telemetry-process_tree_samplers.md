## 1. Goal

Implement pure-Python process-tree telemetry samplers (`ProcessSampler`) in `gunz_utils.telemetry` without third-party C dependencies (`psutil`), providing accurate memory, CPU, and thread metrics across macOS Apple Silicon and Linux execution environments.

## 2. Scope

### In Scope

- **Common Sampler Interface**:
  - `ProcessSample`: Structured snapshot of PID, parent PID, RSS, PSS (where available), thread count, user/system CPU times, and timestamp.
  - Strict "unavailable metric" semantics: missing metrics return `None` rather than fabricating misleading zeros.
- **Linux `/proc` Sampler**:
  - Recursive process-tree discovery via `/proc/[pid]/task/[tid]/children` or parent scans.
  - Precise memory breakdown using `/proc/[pid]/statm` and `/proc/[pid]/smaps_rollup` (PSS, RSS, Private Dirty).
- **macOS Apple Silicon & Darwin Sampler**:
  - Pure Python `/usr/bin/vm_stat`, `sysctl`, or `proc_pidinfo` via `ctypes` bindings to standard `libproc`/`libSystem`.
  - Resident task memory and thread count collection without external build steps.
- **Robustness Invariants**:
  - Process exit race condition resilience: gracefully handles disappearing descendant PIDs during tree traversal without crashing.
  - Background asynchronous sampling loop with configurable sampling rate.

### Out of Scope

- GPU NVML or Metal hardware profiling (deferred to hardware-specific packages).
- Dynamic kernel eBPF tracing.
