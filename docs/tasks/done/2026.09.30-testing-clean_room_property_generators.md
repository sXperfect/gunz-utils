## 1. Goal

Implement clean-room, dependency-free property test generators and a deterministic property assertion runner in `gunz_utils.testkit` to support Program A1 (Property-based invariants) without requiring third-party testing frameworks like Hypothesis at runtime.

## 2. Scope

### In Scope

- **Fuzz Generators**:
  - `fuzz_floats`: Deterministic float generation with configurable bounds, NaN, and Infinity handling.
  - `fuzz_strings`: Configurable min/max length, ASCII/alphanumeric/custom alphabets, edge-case control characters.
  - `fuzz_bytes`: Deterministic byte sequences.
  - `fuzz_primitives`: Deterministic scalar primitive generation (int, float, str, bool, None).
  - `fuzz_json_objects`: Deterministic recursive JSON structures (nested dicts, lists, scalars) with bounded depth and breadth.
- **Property Assertion Runner**:
  - `check_property`: Deterministic test runner executing assertion predicates over generated samples, capturing reproduction seeds, iteration counters, and failing inputs on failure.
- **Invariant Verification**:
  - Exercise real repository contracts using the new generators:
    - Structural deep diff reflexivity (`deep_diff(x, x) == []`).
    - Structured hash stability and key-order independence.
    - Secret redaction containment.
    - TTL Cache capacity bounds.
- **Unit Tests**:
  - `tests/test_core/test_property_generators.py` with standalone execution support under pure Python 3.
- **Documentation & Changelog**:
  - Update `gunz_utils.testkit` exports in `__all__`.
  - Add changelog fragment in `changes/`.

### Out of Scope

- External testing frameworks (Hypothesis, PyTest plugins).
- Non-deterministic random seed defaults (all runs require explicit seed for reproducible failure traces).
