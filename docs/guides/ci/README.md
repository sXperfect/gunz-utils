# CI Guides

This directory contains the durable design rationale for continuous integration
and release validation.

- [CI Design](design.md) — trigger policy, single-runner architecture, ordering,
  permissions, caching, release checks, and required-check policy.
- [Lessons Learned](lessons-learned.md) — concrete findings from real pre-merge
  CI validation and the regressions they should prevent.

The command-level reference remains in `docs/source/ci.md`.
